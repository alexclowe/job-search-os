# Docs

The same guides that ship as PDFs in the [free kit](https://clowealex.gumroad.com/l/job-search-ai-os), as markdown:

- [Jobs guide](./jobs-guide.md): what each of the five jobs asks for, produces, files, and never does.
- [Cheat sheet](./cheat-sheet.md): one page of phrases, the ten prompts worth knowing, the guardrails, and fixes when output does not fit.
- [Skill catalog](./skill-catalog.md): every skill, grouped, generated from the plugin.

These three files are mirrored from the build repository on every release. Suggest edits through a [skill idea issue](https://github.com/alexclowe/job-search-os/issues/new?template=skill-idea.yml).
